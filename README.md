## 🧭 Sobre o projeto

O **ODD — Organizador de Despesas** é um sistema desenvolvido para facilitar o **controle e gerenciamento financeiro**, permitindo organizar despesas e receitas de forma estruturada.

A proposta surgiu da necessidade de substituir controles manuais e planilhas por uma solução capaz de centralizar informações financeiras e apresentar os dados de maneira mais clara.

> **Menos planilhas. Mais organização. Melhores decisões.**

O projeto está sendo desenvolvido como parte da graduação em **Sistemas de Informação** e representa uma aplicação prática dos conhecimentos adquiridos em programação, banco de dados, orientação a objetos e desenvolvimento de sistemas.

---

# 🎯 O problema

Gerenciar despesas manualmente pode rapidamente se tornar complicado.

Planilhas e anotações dificultam:

* 📌 acompanhar despesas;
* 💰 controlar receitas;
* 📅 monitorar vencimentos;
* 📊 visualizar o desempenho financeiro;
* 🔎 localizar informações;
* 📈 identificar padrões de gastos.

O ODD busca resolver esse problema reunindo essas informações em **um único sistema**.

---

# 💡 A solução

O **ODD** centraliza o gerenciamento financeiro em uma única aplicação, proporcionando uma experiência mais simples, organizada e eficiente.

|          💰 **Receitas**          |             💸 **Despesas**            |    📅 **Vencimentos**    |
| :-------------------------------: | :------------------------------------: | :----------------------: |
| Controle das receitas cadastradas | Organização e classificação dos gastos | Acompanhamento das datas |

|         📊 **Indicadores**         |          🔎 **Consultas**          |          📈 **Relatórios**          |
| :--------------------------------: | :--------------------------------: | :---------------------------------: |
| Visão geral da situação financeira | Localização rápida das informações | Análise e acompanhamento financeiro |

> **Centralize suas informações financeiras. Organize seus gastos. Tenha mais controle sobre suas decisões.**

# 🚀 Funcionalidades

### 💸 Controle de despesas

* Cadastro de despesas
* Edição de registros
* Exclusão de registros
* Consulta de despesas
* Classificação entre despesas **fixas e variáveis**
* Controle de status
* Registro de vencimentos

### 💰 Controle de receitas

* Cadastro de receitas
* Edição de registros
* Exclusão de registros
* Consulta de receitas

### 📊 Organização financeira

* Visualização dos registros cadastrados
* Resumo financeiro
* Controle de vencimentos
* Organização das informações financeiras

> 🚧 Novas funcionalidades estão sendo planejadas para futuras versões.

# ⚙️ Como executar

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/bsfJUNIOR/Projeto-ODD.git
```

### 2️⃣ Abra o projeto

Abra o projeto utilizando o **NetBeans 13**.

Crie um banco de dados PostgreSQL para o projeto e configure as informações de conexão utilizadas pelo Hibernate.
